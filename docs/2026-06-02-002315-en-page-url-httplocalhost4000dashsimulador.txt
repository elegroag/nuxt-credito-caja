  Diagnóstico

  Las funciones convertirAnualAMensual y convertirMensualAAnual en
  useSimuladorCore.ts usaban la fórmula de interés compuesto:

  // Antes:
  (Math.pow(1 + ea, 1 / 12) - 1) * 100   // anual → mensual
  (Math.pow(1 + tm, 12) - 1) * 100         // mensual → anual

  Esta fórmula da resultados contraintuitivos para el flujo del input — por
  ejemplo, con EA de 24% daba 1.81% mensual (no 2.00%).

  Solución

  Cambio a conversión simple (÷ 12 y × 12) redondeada a 2 decimales:

  // Ahora:
  const convertirAnualAMensual = (tasaEA: number) => {
    if (!Number.isFinite(tasaEA) || tasaEA <= 0) return 0;
    return Math.round((tasaEA / 12) * 100) / 100;
  };

  const convertirMensualAAnual = (tasaMensual: number) => {
    if (!Number.isFinite(tasaMensual) || tasaMensual <= 0) return 0;
    return Math.round(tasaMensual * 12 * 100) / 100;
  };

  Math.round(n * 100) / 100 es la forma estándar de redondear a 2 decimales
  preservando tipo numérico. El guard Number.isFinite y <= 0 se mantiene para
  los casos borde (NaN, 0, negativos).

  Ejemplos del nuevo comportamiento

  ┌───────────────┬─────────────────────┬──────────────────┬───────────────┐
  │  Tasa anual   │    Tasa mensual     │      Antes       │    Ahora      │
  │     (EA)      │      esperada       │   (compuesto)    │   (simple)    │
  ├───────────────┼─────────────────────┼──────────────────┼───────────────┤
  │ 24.00%        │ 2.00%               │ 1.81% ❌         │ 2.00% ✓       │

  ├───────────────┼─────────────────────┼──────────────────┼───────────────┤

    _tipoTasa?: "anual" | "mensual"
  ) => {
    const ea = tasaEASan / 100;
    if (!Number.isFinite(ea) || ea <= 0) return 0;
    return Math.pow(1 + ea, 1 / 12) - 1;
  };

  con _ para indicar que ya no se usan (compatibilidad con la firma existente en
  useSimuladorWithLinea.ts:92).
